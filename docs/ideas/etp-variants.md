# Ideas for ETP-style projects, with a triage (2026-11-22)

ETP = the Equational Theories Project (https://teorth.github.io/equational_theories), which settled
which of 4,694 short laws about one binary operation imply which.

## Where the idea for our repositories came from

On 2026-11-22, in the first session of this project, the owner asked whether we could start a "new"
Equational Theories Project. The assistant listed ten variants, without checking which were already
done. The owner asked it to pick one and it picked item 3, which became
[eq-unary-magma-laws](https://github.com/Math-Problem-Solving-Using-AI/eq-unary-magma-laws). Its nine
laws with no small model became
[eq-laws-without-small-models](https://github.com/Math-Problem-Solving-Using-AI/eq-laws-without-small-models).
This file records that list, adds the ETP's own list of future directions and ideas from the ETP's
Zulip channel, and checks each item against what exists.

Crowding: **high** = active named people or several groups, **medium** = one active person or
group, **low** = nothing found (which is not proof that nobody is working on it).

## Short list (ranked by fit with what we already built)

1. **#11, laws with a unit constant.** It reuses the `eq-unary-magma-laws` pipeline almost unchanged.
   Repository prepared 2026-11-23: `eq-unit-magma-laws`.
2. **#4, two binary operations, starting at order ≤ 2.** Same pipeline, bigger signature.
   Repository prepared 2026-11-23: `eq-two-operation-laws`.
3. **#5, commutative-only or idempotent-only magmas.** Can reuse ETP data. Needs a classical literature check first.
   Repository prepared 2026-11-23: `eq-commutative-idempotent-magmas`.
4. **#10, quasi-identities and cancellativity.** New kind of statement, so more design work.
   Repository prepared 2026-11-23: `eq-cancellative-magma-laws` (cancellativity first).

Before any of these starts:
- a literature search as deep as `eq-unary-magma-laws/docs/PRIOR_WORK.md`, plus GitHub and Zulip
  (the Zulip archive does not cover March to November 2026);
- an owner decision, one repository per idea (given 2026-11-23 for all four; the literature search
  is queue item 2 of each repository).
