# Triage of the Erdős problems with no prize, 2026-11-22

**No problem was attempted in this pass** (owner's instruction): this file and the dossiers only
*register* candidates so they can be attempted later, one at a time. Registry and queue:
[`REGISTRY.md`](REGISTRY.md).

## What was triaged

- Universe: the 1,107 problems with no prize (`README.md`), restricted to the **561** that the
  community database (2026-11-22) lists as `open`, `falsifiable`, `verifiable` or `decidable`.
- Definition of "low-hanging" used here (from the research prompt): a result could plausibly be
  reached or checked by a **bounded computation or a short argument**, with a **certificate that plain
  code can check**, and the problem is still open by the primary sources we could read. Kinds:
  (i) finite search for a counterexample or extremal value; (ii) checking or extending a conjectured
  formula or integer sequence; (iii) wording that is ambiguous or literally wrong; (iv) looks stale
  (the notes or other sources suggest it is already settled). Excluded: anything needing new deep
  theory, anything we cannot state precisely.

## How

1. **Cheap pass (statement and notes only, no web).** Four subagents each read a quarter of the 561
   problems (statement and notes from the saved page, database status, OEIS field, comment / claim /
   reaction counts) and returned only candidates, with a checkability and a clarity score (0-3) and
   the prior-attempt signals. Result: 93 candidates, table below.
   **These one-liners are leads written by subagents.** They were not checked one by one. One was
   already shown wrong while writing the dossiers: for 887 the subagent proposed a search with
   constant C = 1, which the formal-conjectures file shows cannot give more than one divisor. Treat
   every line as a hypothesis until its dossier exists.
2. **Ranking** of the candidates by: certificate checkability, statement clarity, absence of prior
   attempts (few site comments, no proof claims, nobody "currently working on", no recent OEIS
   entry suggesting someone already computes it), and not a famous conjecture (famous ones have
   surely been searched by computer).
3. **Dossiers** for 10 of them (`dossiers/<number>.md`): statement, the Lean statement and a fidelity
   comparison, a literature check (OEIS, arXiv, GitHub issues, the AI-contributions wiki), first
   concrete step, certificate format, risks, verdict.

Limits that apply to every entry: the site's own pages, LaTeX sources and comment threads were
**not read** (robots.txt disallows Claude agents). Comment threads are where most recent progress
is posted, so every "still open" here means "open according to the database of 2026-11-22, the notes
as of about 2026-10-16, and the sources listed in the dossier".
