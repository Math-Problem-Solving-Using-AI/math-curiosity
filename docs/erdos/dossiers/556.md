# Erdős problem 556: dossier

- **Verdict: `TOO-HARD`.** Small cases n <= 8 are settled, and the first open case n = 9 is a known
  hard Ramsey computation. One wording point (the statement fails at n = 3) is already handled by
  formal-conjectures and the Ramsey survey.
- Database status (2026-11-22): `decidable`, last update 2025-08-31. OEIS: A389335. Statement formalized.
- Site page: https://www.erdosproblems.com/556 (not read). Saved page: 2 comments.

## Statement

Saved page (about 2026-10-16, screen-reader text):

> Let [[R sub 3 of G]] denote the minimal [[m]] such that if the edges of [[K sub m]] are [[3]]
> -coloured then there must be a monochromatic copy of [[G]] . Show that [[R sub 3 of open paren C sub n
> close paren is less than or equal to 4 n minus 3 period]]

Large odd n: Kohayakawa, Simonovits and Skokan [KSS05]. Large even n: Benevides and Skokan [BeSk09]
show R_3(C_n) = 2n.

## What is known

- OEIS A389335 **[read, re-checked]**: data "17,11,17,12,25,16" (n = 3..8), and the formula line "A
  conjecture by Bondy and Erdős: a(n) <= 4n - 3 for n >= 4."
- Radziszowski, "Small Ramsey Numbers", EJC DS1 revision 18 (April 2026), section 6.3.1 **[read by
  subagent]**: "Bondy and Erdős conjectured that R(Cn, Cn, Cn) ≤ 4n − 3 for all n ≥ 4 ... The first open
  case is for R3(C9), known to be at least 33." For even cycles: "The first open case is for R3(C10),
  known to be at least 20." The sources for n = 4..8 are listed in its Table XII (Bialostocki–Schönheim;
  Yang–Rowlinson; Faudree–Schelten–Schiermeyer; Sun–Yang), as relayed by the subagent.
- So: n = 3 is a true exception (17 > 9). n = 4..8 satisfy the bound (n = 5, 7 with equality). n = 9
  is open (lower bound 33 = 4n - 3, so the missing piece is the upper bound). n = 10 is open. We did
  not find explicit thresholds for "sufficiently large" in [KSS05] / [BeSk09] (those papers were not read).

## Formal statement and fidelity

`556.lean` (commit 2207c54, read by us) states `erdos_556 (n) (hn : 4 <= n) : multicolourRamsey
(cycleGraph n) 3 <= 4 * n - 3`, and its docstring explains: "The triangle is excluded: $C_3 = K_3$ and
$R(K_3; 3) = 17 > 9$". Fidelity: matches the intended statement. The site's wording lacks "n >= 4"
(a minor kind-iii point, already known to formal-conjectures and the survey).

## Why not low-hanging

Deciding R_3(C_9) <= 33 means showing that every 3-colouring of K_33 contains a monochromatic 9-cycle.
That is a large SAT / exhaustive problem which experts list as open. Not a hobby-scale computation.

noted.
