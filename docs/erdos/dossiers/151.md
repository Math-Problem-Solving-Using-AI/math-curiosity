## Statement

Saved page (about 2026-10-16, screen-reader text):

> For a graph [[G]] let [[tau of G]] denote the minimal number of vertices that include at least one
> from each maximal clique of [[G]] on at least two vertices (sometimes called the clique transversal
> number). Let [[H of n]] be maximal such that every triangle-free graph on [[n]] vertices contains
> an independent set on [[H of n]] vertices. If [[G]] is a graph on [[n]] vertices then is
> [[tau of G is less than or equal to n minus H of n question mark]]

Notes: tau(G) <= n - sqrt(n) is easy. For triangle-free G the bound is trivial. Erdős and Gallai
"were unable to make progress even assuming [[G]] is [[K sub 4]] -free". Erdős called it "perhaps
completely wrongheaded". Problem 1 in [EGT92].

## Our reading

For every graph G on n vertices: tau(G) <= n - H(n). Here tau counts the vertices needed to hit every
maximal clique with at least 2 vertices (isolated vertices are ignored), and H(n) is the smallest
independence number among triangle-free graphs on n vertices.

**H(n) is known for small n from the Ramsey numbers R(3,k).** Every triangle-free graph on n vertices
has an independent set of size k exactly when n >= R(3,k), so H(n) = max{k : R(3,k) <= n}.
- OEIS A000791 **[read, re-checked]**: data "1,3,6,9,14,18,23,28,36" (R(3,1), ..., R(3,9)).
- Radziszowski, "Small Ramsey Numbers", EJC Dynamic Survey DS1, revision 18 (April 2026)
  **[read by subagent]**: R(3,10) is 40 or 41. Its bibliography includes "V. Angeltveit,
  R(3,10) <= 41".
- So H(n) = 2 for 3 <= n <= 5, 3 for 6-8, 4 for 9-13, 5 for 14-17, ..., 9 for 36-39 (our
  derivation from the table).

Why a small counterexample is conceivable: Erdős himself doubted the conjecture. A graph needs many
maximal cliques that are hard to hit with few vertices, and n - H(n) is close to n for small n. For
example, n = 9 allows tau up to 5.

## Formal statement and fidelity

## Why it looks low-hanging

`falsifiable` means a counterexample would be a finite graph. Checking all graphs on up to 10 vertices
(about 12 million at n = 10) is cheap, and so is a targeted search (for example, graphs with many
triangles and few large cliques) beyond that. A counterexample certificate is a graph plus a
brute-force proof that no hitting set of size n - H(n) exists.

## First concrete step and certificate format

1. Table H(n) from the R(3,k) values above (cite, do not recompute beyond small n). As a sanity
   check, recompute H(n) for n <= 9 by brute force over triangle-free graphs.
2. tau(G): list the maximal cliques of size >= 2 (Bron-Kerbosch), then find a minimum hitting set
   (brute force or ILP).
3. All graphs up to n = 10 (`geng`). Then search n = 11-16 with heuristics (vertex-transitive
   graphs, Paley-type graphs, graphs with clique number 3).
4. Certificates: counterexample = edge list, its maximal cliques, and an exhaustive check of all
   sets of size n - H(n), none of which hits every clique. Negative result: "no counterexample among
   all graphs on n <= N vertices", plus the enumeration counts.
