## Our reading

For n >= 2k >= 2, let p = least prime factor of C(n,k). The claim: p <= max(n/k, k) for all but
finitely many (n,k). The conjectured exceptions are the 14 above. A finite search can find a new
exception (that does not disprove "finitely many", but it would correct the published list), or
confirm "no new exception up to a bound".

Useful fact (standard, Kummer's theorem): p divides C(n,k) iff adding k and n-k in base p has at least
one carry. So each case is decided by small digit computations, and the witness prime p is the
certificate.

## Formal statement and fidelity

`1094.lean` (commit 2207c54, read by us): `{(n,k) | 0 < k ∧ 2*k <= n ∧ (n.choose k).minFac > max (n/k) k}.Finite`.
- `n / k` is natural-number (floor) division. That is harmless here: for an integer p,
  p <= n/k (real) iff p <= floor(n/k). So `minFac > max (n/k) k` is exactly "least prime factor > max(n/k, k)".
- `minFac 1 = 1`, but C(n,k) > 1 for n >= 2k, k >= 1, so there is no junk case.
- Fidelity: **matches** the statement, which is about finiteness and not about the explicit list of 14.
  The explicit list is not formalized.

## Why it looks low-hanging

Each (n,k) is decided by a fast digit test with a one-number witness. A clean, independent,
documented search with certificates (unlike the agent repositories above) is cheap and checkable.
It is evidence, not a proof of finiteness.

## First concrete step and certificate format

1. Read ELS93's search range (owner).
2. For k = 1..K and n = 2k..N(k) (start with N(k) = k^2 and K = 2000, then larger), find the
   least prime p <= max(n/k, k) with a carry in base p. Record exceptions.
3. Certificate: a compressed table, one witness prime per (n,k) or per block, re-checked by an
   independent verifier that recomputes the carry. The exception list is checked by verifying that no
   prime <= max(n/k, k) divides C(n,k) (exact big-integer gcd for small cases).
4. Sanity: the 14 known exceptions must come out exactly. Mutation test: drop one witness and the
   verifier must fail.

## Effort and risks

Small to moderate (about 10^9 cheap cases for K = 2000). Risk: ELS93 or later work may already cover
a larger range, which is why the owner should read ELS93 first.
