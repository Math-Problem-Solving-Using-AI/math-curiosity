## Formal statement and fidelity

`340.lean` (commit 2207c54, read by us) has `erdos_340.variants._33_mem_sub : 33 ∈ Set.range greedySidon
- Set.range greedySidon` marked open. The set difference is over ℕ, so it uses **truncated
subtraction** (a - b = 0 when a < b). For the target 33 > 0 this is harmless, because a - b = 33 forces
a = b + 33. The 0 element of A - A is a junk artefact, which the variants do not rely on. Some test
lemmas use `decide +native` (`../../LEAN_CAVEATS.md` C5).
