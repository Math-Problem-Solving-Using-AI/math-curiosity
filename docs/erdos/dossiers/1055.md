## Statement

Saved page (about 2026-10-16, screen-reader text):

> A prime [[p]] is in class [[1]] if the only prime divisors of [[p plus 1]] are [[2]] or [[3]] . In
> general, a prime [[p]] is in class [[r]] if every prime factor of [[p plus 1]] is in some class [[is
> less than or equal to r minus 1]] , with equality for at least one prime factor. Are there infinitely
> many primes in each class? If [[p sub r]] is the least prime in class [[r]] , then how does [[p sub r
> raised to the 1 divided by r power]] behave?

Notes: "The sequence [[p sub r]] begins [[2 comma 13 comma 37 comma 73 comma 1021]] ( A005113 in the
OEIS)."

## A documented misformalization, now fixed (worth keeping)

formal-conjectures issue #4976, "Erdős 1055: `IsOfClass` does not exclude lower classes, so
`IsOfClass 2 2` holds and `p 2 = 2` instead of 13" (closed 2026-08-16) **[read, re-checked: `gh issue
view`]**: "At `r = 2` the clause meant to force "equality for at least one prime factor" is vacuous,
because `m : ℕ+` and `m ≤ 1` already force `m = 1`." The current file (commit 2207c54, read by us)
adds the conjunct that excludes lower classes, and explains why in its docstring. Added to
`../../LEAN_CAVEATS.md` (C2) as a real example of a statement that type-checked but meant something
else.

## Formal statement and fidelity (current file)

`IsOfClass r p` is defined by strong induction: class 1 when `(p+1).primeFactors ⊆ {2,3}`. Class r > 1
when p is in no lower class, every prime factor of p+1 is in some class <= r-1, and some prime factor
is in no class below r-1. `erdos_1055 r : {p | p.Prime ∧ IsOfClass r p}.Infinite`. Fidelity: matches
the statement, as far as we can read it without building. Sanity value worth a Lean `example`: p 2 = 13.
