## The wording problem (checked by us, also found by formal-conjectures)

That window has C = 1, and with C = 1 no n has more than one divisor in it. The argument, re-derived
by us:
- Let d be a divisor with √n < d < √n + C n^{1/4}, and write d = √n + t with 0 < t < C n^{1/4}.
- Then d + n/d = 2√n + t^2/(√n + t) < 2√n + C^2.
- For d > √n the map d ↦ d + n/d is strictly increasing, and d + n/d is an integer.
- So distinct divisors in the window give distinct integers in the open interval (2√n, 2√n + C^2).
- With C = 1 that interval has length 1, so it holds at most one integer: at most one divisor.

So the 4-divisor result needs a larger constant. formal-conjectures pull request #7218, "fix(ErdosProblems/887):
rosenfeld_4 is false, fix its docstring" (merged 2026-10-22) **[read, re-checked: `gh pr view`]**,
says the same: "With C = 1, every n has at most one divisor in the window."

## Main question

"Is there an absolute K for all C?" is about all large n. No finite computation settles it. Chan
[Ch14, Ch15] solved special cases (squares, almost-squares). arXiv 1303.2069 and 1406.2230
**[abstracts read by subagent]**.

## Formal statement and fidelity

`887.lean`: `parts.i` / `parts.ii` state the main question with windows `Ioo ⌊√n⌋₊ ⌈√n + C n^{1/4}⌉₊`.
Note that `Ioo ⌊√n⌋₊ ...` uses floor and ceiling. Because ⌊√n⌋ <= √n, the lower end can admit d = ⌊√n⌋ + 1,
which is still > √n, so it is fine. The upper end uses ⌈...⌉ with an open interval, which matches
"< √n + C n^{1/4}" for integer d. Fidelity looks right. Not machine-checked by us.
