# Source files for the Erdős triage

Put here the files the triage reads, with the date in the name, for example:

- `prizes-0-2026-11-22.txt` or `.html`: the page https://www.erdosproblems.com/prizes/0 saved from a
  browser. Our automated tool received HTTP 403 from that page, so a person has to save it.

Rules:

- Save the page as you saw it, do not edit it.
- Do not put anything private here, this repository is public.
- The triage prompt is in `docs/prompts/literature-check-and-erdos-triage.md`.
